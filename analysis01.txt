4. Call PaginatedReportEngine.generate_pdf()

STEP 5: PDF GENERATION
================================================================================

File: backend/services/paginated_report_engine.py
Class: PaginatedReportEngine.generate_pdf()

Flow:
1. Create PDF document with SimpleDocTemplate
2. Add title header
3. For each element in elements list:
   - If type == 'chart':
     * Get chart_data from config.get("chart_data")
     * Get chart_type from config.get("chart_type", "bar")  
     * Call generate_chart_image() to create matplotlib chart
     * Add Image to PDF story
   - If type == 'table':
     * Get table_data from config.get("table_data")
     * Create ReportLab Table
     * Add to PDF story with pagination
