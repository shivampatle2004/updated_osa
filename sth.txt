## Project Overview

**OneStopAnalytics** is a full-stack analytics platform with:
- **Frontend**: React + Vite (runs on port 5173)
- **Backend**: FastAPI + SQLAlchemy (runs on port 8010)
- **Database**: SQLite (fallback from PostgreSQL)

## Frontend-Backend Connection

### How Frontend Calls Backend
1. **Vite Proxy Configuration** (`frontend/vite.config.js`):
   ```javascript
   proxy: {
     '/api': { target: 'http://127.0.0.1:8010', changeOrigin: true },
     '/signup': { target: 'http://127.0.0.1:8010', changeOrigin: true },
     '/login': { target: 'http://127.0.0.1:8010', changeOrigin: true },
   }
   ```

2. **Frontend Request Flow**:
   ```
   Frontend (localhost:5173/api/files/upload)
          ↓
   Vite Proxy redirects to
          ↓
   Backend (127.0.0.1:8010/api/files/upload)
   ```

### Starting the Application
```bash
# Terminal 1 - Start Backend
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8010 --reload

# Terminal 2 - Start Frontend
cd frontend
npm run dev
```

## Database Models & Flow

### Core Models (models.py)

```python
# User authentication
class User:
    id: Integer (PK)
    email: String (unique)
    hashed_password: String
    full_name: String

# Uploaded files (datasets)
class UploadedFile:
    id: String (UUID, PK)
    file_name: String
    file_path: String
    row_count: Integer
    column_count: Integer
    status: String  # pending, processing, completed, failed

class FileColumn:
    id: String (UUID, PK)
    file_id: String (FK)
    column_name: String
    data_type: String  # numeric, categorical, datetime
    null_count: Integer
    unique_count: Integer

# ETL System
class ETLConnection:
    id: String (UUID, PK)
    user_id: Integer (FK)
    name: String
    conn_type: String  # postgresql, mysql, csv, etc.
    host, port, database, username, encrypted_password

class ETLPipeline:
    id: String (UUID, PK)
    name: String
    status: String  # draft, active, archived
    nodes: relationship(ETLWorkflowNode)
    edges: relationship(ETLWorkflowEdge)
    schedules: relationship(ETLSchedule)

# Remote Database Connections
class RemoteConnectionProfile:
    id: String (UUID, PK)
    user_id: Integer (FK)
    connection_name: String
    db_type: String
    host, port, database, username
    encrypted_password: Text

# Data Vault
class DataVaultItem:
    id: String (UUID, PK)
    name: String
    source_name: String  # mysql, excel, csv
    file_id: String (FK to UploadedFile)
    table_name: String

# Paginated Reports
class PaginatedReport:
    id: String (UUID, PK)
    name: String
    user_id: Integer (FK)
    page_size: String  # A4, Letter
    orientation: String  # portrait, landscape

class PaginatedReportElement:
    id: String (UUID, PK)
    report_id: String (FK)
    type: String  # table, text, image
    config_json: JSON

class PaginatedReportDataSource:
    id: String (UUID, PK)
    report_id: String (FK)
    query: String (SQL query)
    connection_id: String  # file_id OR remote profile id
```

### Database Initialization Flow
```python
# database.py
def init_db():
    1. Create all tables (Base.metadata.create_all)
    2. Migrate old columns (_ensure_remote_connection_profile_columns)
    3. Seed connector catalog (seed_connectors)
```

## Paginated Reports System

### Architecture Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         PAGINATED REPORTS FLOW                             │
└─────────────────────────────────────────────────────────────────────────────┘

  FRONTEND                           BACKEND                              DATABASE
    │                                   │                                      │
    │  1. Create Report                │                                      │
    │  POST /api/reports/create         │                                      │
    │  { name, page_size, orientation,  │                                      │
    │    elements: [{type, config}],   │                                      │
    │    data_sources: [{query,         │                                      │
    │      connection_id}] }           │                                      │
    ├──────────────────────────────────▶│                                      │
    │                                   │  2. Save to DB                      │
    │                                   │  INSERT paginated_reports           │
    │                                   │  INSERT paginated_report_elements   │
    │                                   │  INSERT paginated_report_data_sources│
    │                                   ├────────────────────────────────────▶│
    │                                   │◀────────────────────────────────────┤
    │◀──────────────────────────────────┤  3. Return report_id                 │
    │   { id, message }                │                                      │
    │                                   │                                      │
    │  4. Generate PDF                 │                                      │
    │  POST /api/reports/{id}/generate-pdf                                    │
    ├──────────────────────────────────▶│                                      │
    │                                   │  5. Fetch Report                   │
    │                                   │  SELECT * FROM paginated_reports   │
    │                                   │  WHERE id = report_id              │
    │                                   ├────────────────────────────────────▶│
    │                                   │◀────────────────────────────────────┤
    │                                   │  6. For each data_source:         │
    │                                   │     - If connection_id is file_id: │
    │                                   │       Load from UploadedFile       │
    │                                   │     - If query exists:             │
    │                                   │       Execute SQL on remote DB    │
    │                                   │                                      │
    │                                   │  7. Generate PDF using            │
    │                                   │     PaginatedReportEngine          │
    │                                   │                                      │
    │◀──────────────────────────────────┤  8. Return PDF (binary)           │
    │   PDF File                        │                                      │
```

### Data Source Connection Types

The `PaginatedReportDataSource` supports **2 types of connections**:

#### Type 1: File-based (Dataset)
```python
# connection_id = file_id (from UploadedFile)
file_record = db.query(UploadedFile).filter(UploadedFile.id == connection_id).first()
df = ModelEngine.load_report_dataframe(connection_id, db)
data = df.to_dict(orient='records')
```

#### Type 2: Remote Database (Custom SQL)
```python
# connection_id = remote profile id + query provided
data = execute_paginated_select(
    query=query,
    profile_id=connection_id,  # RemoteConnectionProfile ID
    limit=10000
)
```

### Example API Usage

```javascript
// 1. Create a report with table element and file data source
const createResponse = await fetch('/api/reports/create', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: "Sales Report",
    page_size: "A4",
    orientation: "portrait",
    elements: [
      {
        type: "table",
        config_json: {
          data_source_index: 0,
          columns: ["date", "sales", "product"],
          title: "Monthly Sales"
        }
      }
    ],
    data_sources: [
      {
        connection_id: "file-uuid-here",  // UploadedFile ID
        query: null
      }
    ]
  })
});

// 2. Generate PDF
const pdfResponse = await fetch('/api/reports/{report_id}/generate-pdf', {
  method: 'POST'
});

// Download PDF
const blob = await pdfResponse.blob();
const url = URL.createObjectURL(blob);
window.open(url);
```

## API Endpoints

### Files API (`/api/files`)
| Method | Endpoint | Description |
|--------|-----------|-------------|
| POST | `/api/files/upload` | Upload CSV/Excel file |

## Key Services

### Backend Services (`backend/services/`)

| Service | Purpose |
|---------|---------|
| `data_processor.py` | Read/parse CSV, Excel, JSON files |
| `model_engine.py` | Load datasets, cache management |
| `sql_execute.py` | Execute SQL on remote databases |
| `paginated_report_engine.py` | Generate PDF reports |
| `graph_engine.py` | Create chart definitions |
| `smart_analyzer.py` | AI-powered insights |
| `remote_db_manager.py` | Manage remote DB connections |
| `etl_executor.py` | Run ETL pipelines |
| `etl_scheduler.py` | Schedule ETL jobs |

### Data Flow for File Upload

```
1. Frontend sends file → /api/files/upload
2. Backend saves to backend/uploads/{uuid}.{ext}
3. Creates UploadedFile record (status=pending)
4. Background task (tasks.py) processes file:
   - Read CSV/Excel with DataProcessor
   - Infer column types
   - Calculate statistics
   - Update status=completed
5. Frontend polls /api/files/{id}/status
```

## Troubleshooting

### Common Issues

1. **HTTP 500 on Dataset Load**
   - Check backend is running: `curl http://127.0.0.1:8010/docs`
   - Check file status: `/api/files/{file_id}/status`
   - Verify file exists in `backend/uploads/`

2. **Upload Fails**
   - Verify file format allowed: csv, xlsx, xls, json, txt, tsv, parquet
   - Check file size limit

3. **PDF Generation Fails**
   - Verify data_source has valid connection_id
   - Check file is still available in uploads
