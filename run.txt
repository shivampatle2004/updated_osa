=======================================
ONESTOPANALYTICS - RUN INSTRUCTIONS
=======================================

These are the step-by-step instructions to set up and run the OneStopAnalytics project manually on a Windows system.

PREREQUISITES:
1. Python installed (recommended: Python 3.10 or 3.11).
2. Node.js installed (LTS version recommended).
3. PostgreSQL server running locally (or remotely) matching the credentials in `backend/.env`.

---------------------------------------
STEP 1: DATABASE ENVIRONMENT SETUP
---------------------------------------
A `.env` file has already been created in the `backend` directory (`d:\OSA\backend\.env`) with the following defaults:
DB_USER=postgres
DB_PASSWORD=12345
DB_HOST=localhost
DB_PORT=5432
DB_NAME=onestopanalytics

Note: Ensure your local PostgreSQL service is running and configured with the above password/username, and the database `onestopanalytics` exists (or allows creation).

---------------------------------------
STEP 2: AUTOMATED SETUP (RECOMMENDED)
---------------------------------------
If you haven't installed dependencies yet, you can use the predefined script:
from the root directory (`d:\OSA`), double click on `setup.bat` or run:
> setup.bat
This script will automatically:
- Create a Python virtual environment (`venv`).
- Install all backend dependencies via `pip`.
- Install frontend dependencies via `npm`.

---------------------------------------
STEP 3: RUN THE BACKEND
---------------------------------------
1. Open a new Command Prompt or PowerShell window.
2. Navigate to the backend directory:
   > cd /d "d:\OSA\backend"
3. Activate the virtual environment:
   > venv\Scripts\activate
4. Run the FastAPI application using Uvicorn:
   > uvicorn main:app --host 127.0.0.1 --port 8010 --reload

Leave this terminal open. The backend API is now running on http://127.0.0.1:8010.

---------------------------------------
STEP 4: RUN THE FRONTEND
---------------------------------------
1. Open another new Command Prompt or PowerShell window.
2. Navigate to the frontend directory:
   > cd /d "d:\OSA\frontend"
3. (Optional) Set your .env in the frontend if needed, but none is strictly requested at the moment.
4. Start the Vite development server:
   > npm run dev

Leave this terminal open. Vite will provide you with a local host link where you can visit the UI (typically http://localhost:5173).

---------------------------------------
STEP 5: ACCESS THE APPLICATION
---------------------------------------
Open your web browser and navigate to the frontend URL (e.g., http://localhost:5173) to see your project running perfectly!
